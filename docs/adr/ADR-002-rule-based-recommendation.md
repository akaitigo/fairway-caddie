# ADR-002: ルールベースのクラブ推薦エンジン (MVP)

## Status
Accepted

## Context
ユーザーの飛距離分布とハザード位置から「期待値が最も高いクラブ」を推薦する機能が必要。
推薦アルゴリズムの選択肢:

1. ベイズ推定ベース: データ蓄積後に高精度な推薦が可能だが、実装コスト大
2. 機械学習 (Python ML): 精度は高いがインフラ構築が必要
3. ルールベース (正規分布近似 + 閾値判定): 実装が軽量で、MVPとして十分

## Decision
**ルールベース (正規分布近似 + 閾値判定)** を採用する。

### 期待値計算式
```
期待値 = フェアウェイ/グリーンオン確率 - (ハザード到達確率 x ペナルティコスト)
```

- 各クラブの飛距離分布を正規分布 N(mu, sigma) で近似
- 正規分布の CDF を使い、ターゲット到達確率とハザード到達確率を算出
- ペナルティコストはハザード種別で固定 (water: 2, bunker: 1, ob: 3)

### コールドスタート対策
- 5ラウンド未満のデータではジェネリック推薦（クラブ種別ごとの汎用統計）を使用
- ジェネリック推薦は固定値（プロ平均統計ベース）を使用

### インターフェース抽象化
- `RecommendationEngine` インターフェースを定義
- MVP: `RuleBasedEngine` が実装
- Phase 2: `BayesianEngine` / `MLEngine` に差し替え可能

## Consequences

### Positive
- MVP として最速で実装可能
- 推薦の根拠（確率・期待値）を数値で表示可能
- インターフェース抽象化により将来の ML 移行がスムーズ

### Negative
- 正規分布近似の精度限界（実際の飛距離分布は歪みがある場合がある）
- ハザードペナルティコストが固定値のため、コース特性を反映しきれない

### Risks
- コールドスタート時のジェネリック推薦がユーザー体験を損なう可能性
  - 緩和策: 推薦の信頼度をデータ量に応じて表示
